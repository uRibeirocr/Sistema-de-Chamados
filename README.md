# Sistema de Chamados

Sistema de gerenciamento de chamados desenvolvido em Python.

## Sobre o projeto

Este projeto tem como objetivo criar um sistema simples para gerenciamento de chamados de TI.

O sistema permite que usuários façam login e tenham acesso a diferentes funcionalidades  de acordo com seu tipo de usuário.

## Funcionalidades 

[x] Sistema de login
[x] Autenticação de usuários
[x] Identificação do tipo de usuário
[x] Menu principal
[x] Abrir chamado
[x] Listar chamados
[x] Consultar chamado
[x] Alterar status do chamado
[x] Armazenar chamados

## Tecnologias utilizadas
